# Hybrid CNN-BiLSTM Framework for PM2.5 Prediction

Predicting PM2.5 air pollution concentration using a hybrid 
deep learning pipeline combining 1D-CNN and BiLSTM.

## Models Compared
- Linear Regression
- Random Forest
- LSTM
- GRU
- CNN-BiLSTM (Proposed)

## Best Result
- MAE  : 0.0120
- RMSE : 0.0181
- R²   : 0.3914
- MAPE : 90.73%

## Tech Stack
Python | TensorFlow | Keras | Scikit-learn | Google Colab

## Dataset
Multivariate air quality dataset — PM2.5, PM10, SO2, 
NO2, Temperature, Humidity, Wind Speed, Pressure.
